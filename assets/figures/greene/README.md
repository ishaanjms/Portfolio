# Counsel — Greene's Counsel thumbnail

Two speech bubbles represent asking for guidance and receiving a structured
reply. The question rises first; pieces of advice then lift from the response.
The tour visits question, perspective, next step, then rest.

`counsel.js` uses Hairline's unchanged kernel. `hairline-counsel.html` is the
self-contained preview; append `?play=1` to play the tour. The website mounts
the same figure through `js/hairline-thumbnails.js`, with passive motion and
the entire thumbnail as a project link.

The figure uses fixed hit positions, bounded spring motion, one highlight,
opaque speech plates and off-screen pausing. Slider values set a maximum
lift of 6, 14, and 22 world units.

Build and validate the HTML with the official tools in Hairline's skill:
https://github.com/lucasmarkes/hairline/tree/main/skills/hairline-create
